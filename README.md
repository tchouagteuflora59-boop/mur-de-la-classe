# 🇨🇲 Villes du Cameroun

Une page web interactive qui permet de découvrir une sélection de villes
et localités du Cameroun, organisées par région.

## Aperçu

Le projet propose une interface simple, moderne et responsive pour
parcourir les villes camerounaises. Les utilisateurs peuvent rechercher
une ville par son nom ou filtrer les résultats selon l'une des dix
régions du pays.

## Fonctionnalités

-   Affichage d'une sélection de villes et localités du Cameroun.
-   Organisation des villes par région administrative.
-   Recherche dynamique par nom de ville.
-   Filtrage par région.
-   Réinitialisation rapide de la recherche et des filtres.
-   Cartes animées à l'affichage.
-   Effets visuels au survol des cartes.
-   Interface adaptée aux ordinateurs, tablettes et smartphones.

## Technologies utilisées

-   **HTML5** : structure de la page.
-   **CSS3** : mise en forme, responsive design et animations.
-   **JavaScript** : affichage dynamique, recherche et filtrage.

Aucun framework ni installation de dépendance n'est nécessaire.

## Utilisation

1.  Ouvrez la page d'accueil.
2.  Saisissez le nom d'une ville dans la barre de recherche pour la
    retrouver.
3.  Utilisez le menu déroulant pour afficher uniquement les villes d'une
    région.
4.  Cliquez sur **Réinitialiser** pour afficher à nouveau toutes les
    villes.

## Personnalisation

-   Pour ajouter ou modifier des villes, éditez le tableau `cities` dans
    `script.js`.
-   Pour changer les couleurs, les espacements ou les animations,
    modifiez `style.css`.
-   Pour modifier le contenu ou la structure de la page, éditez
    `index.html`.

Chaque ville est associée à une région dans le tableau JavaScript. Les
régions du filtre sont générées automatiquement à partir de ces données.

## Données

La liste proposée est une sélection de villes et localités
camerounaises. Elle n'est pas exhaustive et ne constitue pas un
répertoire administratif officiel de toutes les communes du Cameroun.
